## Appendix A — control-socket driver (terminal 3)

Protocol v1: JSON lines over the per-run unix socket
`<BC_DATA_DIR>/runs/run-<run_id>.sock` (also on the Run row as
`control_sock`). Actions: `screenshot`, `elements`, `context`,
`click {n}`, `fill {n, text}`, `press {key}`, `drag {n, dx, dy}`,
`resume`, `cancel`.

```python
# /tmp/bc-d64/driver.py
# usage (from apps/): .venv/bin/python /tmp/bc-d64/driver.py <run_id>
import sys
from billcollector.control import ControlClient

run_id = sys.argv[1]
c = ControlClient(f"/tmp/bc-d64/data/runs/run-{run_id}.sock")

def show():
    for el in c.request("elements")["elements"]:
        print(el["n"], el["role"], el.get("name", ""))

show()                                   # find the checkbox number
c.request("click", n=int(sys.argv[2]))   # pass it as the 2nd argument
show()                                   # Verified button now listed
c.request("resume")
print("resumed")
```

`context` returns the machine-readable pause payload (url, step error,
numbered elements, page text) — the same data the detail pause card shows.
